Stack Memory Layout - Function Call Demonstration

Step 1: Program starts - main() is called

Source Code

Text Section (Read-only)

Machine code for main(), func1(), func2()
String literals: "Hello", "World"
int main() {
    int a = 10;
    func1(a);
    return 0;
}

int func1(int x) {
    int b = 20;
    func2(x, b);
    return x + 1;
}

int func2(int p, int q) {
    int result = p * q;
    return result;
}

Stack Memory (grows downward)

Memory Layout Explanation:

Text Section: Contains compiled machine code and constants (fixed size, read-only)

Stack: Contains function call information (dynamic, grows/shrinks with calls)

Each Stack Frame contains:

  • Return address (where to go after function ends)
  • Function parameters
  • Local variables
  • Saved registers
