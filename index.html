Get Connected
🔑
Step 1 — LinkedIn API
Required for inbox & messaging
1
Go to linkedin.com/developers/apps and create an app
2
Enable: Sign In with LinkedIn, Share on LinkedIn, Marketing Developer Platform
3
Set redirect URL to http://localhost:3000/callback
4
Copy credentials to .env file in your project
5
Run node mcp/oauth-setup.js to get your access token
⏰
Step 2 — Schedule Tasks
7am inbox + trend report, 5pm team report
1
Run bash scripts/install-cron.sh to register all cron jobs
2
Verify with crontab -l — you should see 3 entries
3
Reports appear in logs/ folder each morning
💬
Step 3 — Slack Reports
Optional — post daily report to team channel
1
Create a Slack app at api.slack.com/apps
2
Add SLACK_BOT_TOKEN and SLACK_REPORT_CHANNEL to your .env
📱
Step 4 — Mobile Access
Access Claude from your phone
1
Run python3 -m http.server 8080 in your project folder
2
Open your machine's local IP on your phone: http://<your-ip>:8080
3
For remote access: install ngrok, then run ngrok http 8080 to get a public URL
4
Bookmark the URL on your phone's home screen for instant access
